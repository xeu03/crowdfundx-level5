# Demo Video Script — Level 5 (1–2 minutes)

Record with Loom / OBS / screen recorder, 1080p. Keep it under 2 minutes —
the graders want a full product walkthrough showing user flow and real use
cases.

## Scene plan (~15s each)

1. **Intro** (0:00–0:15)
   - Live demo URL, "CrowdfundX — all-or-nothing crowdfunding on Stellar"
   - Header: network badge (online), USD toggle, wallet button.

2. **Explore + live data** (0:15–0:30)
   - 7 campaigns on the grid; platform stats tiles.
   - Click the **USD** toggle — approximate dollar values appear.

3. **Wallet + contribute** (0:30–0:50)
   - Connect Freighter → header shows CFX balance + address.
   - Open a campaign → contribute → wallet signs → success toast.
   - Live activity feed updates instantly.

4. **Notification bell** (0:50–1:05)
   - Click 🔔 Notify me about milestones → allow browser notifications.
   - (If recording live: release a milestone and the OS notification pops.)

5. **Growth proof** (1:05–1:30)
   - Leaderboard: 51 wallets ranked from 56 on-chain contribution events.
   - Feedback widget: submit a rating.

6. **Close** (1:30–1:45)
   - One-liner: "Anyone can fund anyone — verified on-chain."
   - GitHub link + pitch deck mention.

## Before recording

- Hard-refresh the live demo (clear toasts).
- Have a second wallet ready as the backer.
- Pre-mint CFX to that wallet: `scripts/faucet.sh <address>`.
- Upload the recording to YouTube (unlisted) or Loom with a share link,
  then paste the link into the README checklist.
